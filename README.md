# IPL MELIon
An end-to-end IPL data analytics project featuring data profiling, preprocessing, exploratory analysis, and insightful visualizations.
There are about more then 30 Analysis performed on the Dataset with Visualizations.

## Getting started

```bash
pip install -r requirements.txt
```

### Website (interactive dashboard)

```bash
streamlit run app.py
```

Then open http://localhost:8501. The dashboard covers the overview, batting, bowling, fielding, teams
(head-to-head, captains, squads), toss & results, venues & umpires, season awards and a player explorer,
all filterable by season range.

### Notebooks

```bash
jupyter notebook
```

Open `IPL .ipynb` or `BallByBall_Analysis.ipynb` and run all cells. The CSV files must stay in the same
folder as the notebooks.
